# Portfolio - Kalebe Vasconcelos

Bem-vindo(a) ao repositório do meu portfólio pessoal! Este projeto apresenta minhas habilidades, experiências profissionais, formação acadêmica e os projetos que desenvolvi como estudante de Engenharia de Software e Desenvolvedor.

## 🚀 Sobre o Projeto

Este portfólio é um site estático e responsivo construído com **HTML5, CSS3 e JavaScript**. O objetivo é fornecer uma interface moderna e limpa para destacar minha trajetória profissional e meus conhecimentos técnicos.

## 🛠️ Tecnologias Utilizadas

- **HTML5** para a estrutura semântica da página.
- **CSS3** para estilização (incluindo animações, flexbox, grid e design responsivo).
- **JavaScript** para interatividade.
- **FontAwesome** para os ícones.
- **Google Fonts** (fonte Outfit) para a tipografia.

## 📂 Funcionalidades e Seções

- **Projetos:** Destaque para os meus principais projetos com links para os repositórios no GitHub e páginas ao vivo (E-Pidgey, TecnoK, BISU, etc.).
- **Experiência e Formação:** Uma seção com abas interativas detalhando meu histórico acadêmico (Engenharia de Software na UEPA, Técnico em Informática no IFPA), cursos extracurriculares e experiências de trabalho.
- **Habilidades (Skills):** Uma lista abrangente das minhas *Hard Skills* (Python, PHP, Java, JS, HTML/CSS, Git, Linux) e *Soft Skills* (Trabalho em equipe, Resolução de problemas).
- **Contato:** Links rápidos para as minhas redes sociais profissionais.
